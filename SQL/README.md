This folder contains all SQL scripts used in the Telecom SIM Activation & Deactivation Analytics project.

Creates the database table.

### cleaning.sql
Contains data cleaning queries.

### analysis.sql
Contains aggregation queries.

### kpi_queries.sql
Contains KPI calculations.

### views.sql
Contains SQL Views.

### window_functions.sql
Contains Window Function queries.
